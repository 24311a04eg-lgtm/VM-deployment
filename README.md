# Flask CI/CD Pipeline

A simple project demonstrating a complete CI/CD workflow using GitHub Actions and AWS EC2.

## Project Structure

```text
.
├── .github/
│   └── workflows/
│       ├── ci.yml
│       └── cd.yml
├── templates/
│   └── index.html
├── tests/
│   └── test_app.py
├── app.py
├── requirements.txt
└── .gitignore
```

## CI Pipeline

The CI workflow runs on every push and pull request to the `main` branch.

It performs the following steps:

* Checks out the repository
* Sets up Python 3.12
* Installs project dependencies
* Runs unit tests using `pytest`
* Creates a deployment artifact (`app.zip`)
* Uploads the artifact for the CD pipeline

## CD Pipeline

The CD workflow starts automatically after the CI workflow completes successfully.

Deployment process:

1. Downloads the artifact generated by CI
2. Configures SSH authentication
3. Deploys to **VM1**
4. Verifies deployment using a health check
5. Deploys to **VM2**
6. Verifies deployment using a health check

This implements a simple **rolling deployment**, ensuring the second VM is updated only after the first VM passes its health check.

## Testing

Unit tests verify:

* Home endpoint (`/`)
* Health endpoint (`/health`)

Run tests locally:

```bash
python -m pytest
```
